# Feedback and contributions

TrashBeats is a course prototype. Reports about confusing interactions, audio behavior, or reproducible crashes are welcome in Issues. Please include your OS, Godot/app version, exact steps, expected behavior and actual behavior. A small screenshot or non-sensitive example helps.

Do not include API keys, local recordings of other people, or private filesystem details in reports. Cloud API access is optional and not required to report problems with the local sequencer.

Before proposing a substantial code contribution, discuss it in an issue. Original source code is licensed under MIT. Contributions should be your own work or include compatible license and attribution details.

For a code change, run the isolated smoke test described in [docs/BUILDING.md](docs/BUILDING.md), and describe any manual checks. Keep changes focused. Generated `.godot` caches, export credentials, engine binaries and personal recordings do not belong in the source tree.
